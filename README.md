# Mouzan Raza — Portfolio

Personal portfolio website for Mouzan Raza, an AI / ML engineer building production-ready AI applications.

## Stack

- Next.js 16 (App Router, Turbopack)
- Tailwind CSS v4
- Framer Motion (3D tilt cards + hero shapes)
- GitHub REST API (live stats)
- Custom rule-based chatbot (zero external LLM dependency)

## Features

- AI chatbot that answers questions about Mouzan from a built-in knowledge base
- 3D hero shapes (wireframe cube, pyramid, rings) + 3D tilt cards
- Live GitHub stats and top repositories
- Scroll progress bar
- Dark / light mode
- Resume download (DOCX / PDF)
- Contact form

## First Portfolio

This project is a redesign inspired by the **Sawad** Framer portfolio template —
[First Portfolio — Sawad Template](https://www.framer.com/community/marketplace/templates/sawad/)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```
